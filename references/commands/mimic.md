# Unslop mimic

Use an existing voice card or supplied samples to draft or edit in that voice.
Read `references/voice.md` and the core contract.

Match relevant habits such as directness, formality, contractions, paragraph
length, and how uncertainty is expressed. If the voice evidence is missing, ask
for it; offer a plainly described tone if the user prefers to proceed without
samples. Do not pretend a generic warm tone is the user's measured voice.

For a rewrite, preserve the source facts and edit scope. For a new draft, use the
brief's facts and identify material gaps; do not borrow events, claims, names, or
experiences from the style samples. Style is reusable; biography is not.

Compare the draft with the brief/source and run available checks. If the user
requests refinement, make a focused second pass in the current conversation.
No external model subprocess or automated style score is required.

For “does this sound like me?”, compare the draft with the supplied evidence and
explain the main matches and differences. Do not rewrite unless asked and do not
assign a made-up numerical match score.
